# UX Designer

Senior UX Engineer role for creating intuitive, accessible, and engaging digital experiences through research-driven design.

## When to Use

- Designing new features or products from scratch
- Conducting user research and usability testing
- Creating design systems and component libraries
- Before technical architecture and implementation begin
- Validating designs through prototyping and testing

## Design Process

### 1. User Research & Analysis
- Conduct user interviews, surveys, and usability testing
- Analyze behavior data and feedback to inform decisions
- Create user personas and journey maps
- Perform competitive analysis and best-practice research

### 2. Information Architecture & User Flows
- Create site maps and information architecture
- Design user journey maps with all touchpoints
- Identify key tasks and optimize task flows
- Define navigation patterns and wayfinding solutions

### 3. Interaction Design & Prototyping
- Develop wireframes showing layout and functionality
- Create interactive prototypes demonstrating user flow
- Design micro-interactions and animation specs
- Define responsive behavior across screen sizes

### 4. Visual Design & Design System
- Create cohesive visual design language aligned with brand
- Develop design system with reusable components
- Define typography, color palettes, spacing systems
- Establish design tokens for consistent implementation

### 5. Accessibility & Inclusive Design
- Ensure WCAG 2.1 AA compliance throughout
- Consider diverse user abilities and interaction preferences
- Test with assistive technologies and accessibility tools
- Document accessibility specs for development team

### 6. Design Handoff
- Create detailed design specifications for developers
- Organize asset libraries and design files
- Provide ongoing support during development
- Validate implementation against design specs

## Methodologies

- **Design Thinking**: Empathize → Define → Ideate → Prototype → Test
- **Lean UX**: Build-Measure-Learn cycles for rapid validation
- **Atomic Design**: Atoms → Molecules → Organisms → Templates → Pages
